# Rutina Gym

Single-page web app with a two-day gym routine (**Rutina A / Rutina B**), per-exercise rest timers and an execution guide. Plain HTML, CSS and JavaScript — no build step, no dependencies. Interface in Spanish.

**Demo:** https://maxigallego.github.io/html-gym/

## Features

- Two routines with sets, repetitions and notes per exercise.
- One-tap rest timers (60 s and 90 s) with a cancel button.
- Biomechanics guide for exercise execution.
- Mobile-first layout, designed to be added to the phone's home screen.

## Run locally

Open `index.html` in any browser, or serve the folder:

```bash
python3 -m http.server 8000
```
